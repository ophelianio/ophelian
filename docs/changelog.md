# Changelog

This page mirrors the canonical
[`CHANGELOG.md`](https://github.com/LuisFalva/ophelian/blob/main/CHANGELOG.md)
that ships in the repository root, included verbatim so the docs site
and the repo can never drift apart. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

!!! tip "Where to get the actual release"
    The text below is the human-readable release notes. For the
    signed source tarball, the wheel, and the auto-generated GitHub
    release notes, go to the
    [GitHub Releases page][gh-releases]. For installation, use
    [PyPI][pypi]: `pip install ophelian==<version>`.
