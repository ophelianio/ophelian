# Security

If you have found a security issue in Ophelian, **please do not open a
public GitHub issue, discussion, or pull request.** Use one of the
private channels documented below.

!!! danger "Report privately"
    The fastest, most secure path is GitHub's
    [Private Vulnerability Reporting][advisory-new] — the green
    **"Report a vulnerability"** button on the repo's
    [Security tab][security-tab]. It is end-to-end private, requires
    no email round-trip, and triages directly into a GitHub Security
    Advisory if accepted.

The full policy below is the canonical
[`SECURITY.md`](https://github.com/LuisFalva/ophelian/blob/main/SECURITY.md)
that ships in the repository root, included verbatim so the docs site
and the repo can never drift apart.
